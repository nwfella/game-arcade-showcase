# 🎮 Game Arcade — Portfolio Showcase

A grid-based portfolio of single-file HTML5 canvas game homages and originals. All games are zero-dependency, deployable on GitHub Pages, and playable in the browser.

**Live:** https://nwfella.github.io/game-arcade-showcase/

## Features

- **3×1 responsive grid** — 3-col desktop, 2-col tablet, 1-col mobile
- **Per-card accent colours** — each game has its own themed palette
- **Animated preview icons** — floating, pulsing, spinning elements per game
- **Animated starfield background** — dynamic canvas parallax stars
- **CRT scanline overlay** — subtle retro monitor effect
- **All single-file** — zero dependencies, one HTML file

## Tech

- Vanilla HTML/CSS/JS
- Canvas 2D for starfield
- CSS custom properties for theming
- GitHub Pages deployment
